Student Management Portal - prototype (HTML + CSS + JavaScript)

HOW TO RUN
1. Keep index.html, style.css and script.js in the same folder.
2. Double-click index.html to open it in Chrome / Edge / Firefox.
3. Choose a role (Admin, Faculty, Student) and click "Enter Portal".

NOTES
- Demo login only: no real password check. Do not use real student data.
- Data is saved in the browser (localStorage). Admin can use "Reset demo data".
- All names and numbers are fictional sample data.
- "Smart Insights" is rule-based (attendance below 75%, low marks), not a trained ML model.
